# Task 5: Decision Trees and Random Forests

## Objective
To understand and implement tree-based machine learning models for classification and evaluate their performance.

## Steps Performed
1. Loaded the Heart Disease dataset using Pandas.
2. Split the dataset into training and testing sets.
3. Trained a Decision Tree Classifier on the training data.
4. Visualized the Decision Tree to understand its decision-making process.
5. Analyzed overfitting by training multiple Decision Trees with different maximum depths and comparing training and testing accuracies.
6. Selected an appropriate tree depth to control overfitting.
7. Trained a Random Forest Classifier and compared its accuracy with the Decision Tree.
8. Evaluated the importance of each feature using Random Forest feature importance scores.
9. Visualized feature importance using a bar chart.
10. Performed 5-Fold Cross Validation to measure the model's stability and generalization performance.

## Result
The Random Forest model achieved higher accuracy and better generalization than the Decision Tree. Cross-validation results indicated consistent performance across different data splits.
